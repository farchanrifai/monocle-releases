## How to Install on iOS

### Option A: Using SideStore
1. Tap the **Add to SideStore** badge at the top or open SideStore.
2. Go to the **Sources** tab, tap **`+`** in the top-right corner, and paste the Source URL.
3. Find **Nook** and tap **Install** / **Update**.

### Option B: Using LiveContainer
1. **Via Sources**: Tap the **Add to LiveContainer** badge at the top, or go to LiveContainer → **Sources** → **`+`** and paste the Source URL.
2. **Via Direct URL**: Tap the **`+`** button in LiveContainer, select **Install from URL**, and paste the [Direct IPA Link](https://github.com/farchanrifai/monocle-releases/releases/download/nook-v1.0.15-build.18/nook-1.0.15-build-18-unsigned.ipa).
